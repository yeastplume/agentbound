# Architecture specifications

This directory will contain implementation-level specifications produced during Phase 1, including:

- normative requirements and threat-model scope;
- session request and effective-manifest schemas;
- lifecycle and failure-state definitions;
- privileged/unprivileged interface specifications;
- audit event and correlation schemas;
- architecture decision records.

The directory is intentionally empty of design commitments until the Phase 1 plan has been reviewed.

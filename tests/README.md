# Conformance and adversarial tests

This directory is reserved for reproducible tests mapped to the technical report's security invariants and the Phase 1 gates.

The suite covers session interference, escape and persistence, credential recovery, gateway bypass, resource exhaustion, lifecycle fault injection, and audit reconstruction. Results use the five conformance classes in the Phase 1 plan §7.2 and the test IDs in `docs/architecture/test-catalogue.md`.
